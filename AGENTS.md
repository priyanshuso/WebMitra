# WebMitra Agent Instructions

This repository contains a static marketing website for WebMitra.

## Project goals
- Keep the site simple, fast, and dependency-free.
- Maintain consistent styling and content across the static pages.
- Preserve SEO information, contact details, and accessibility standards.

## Working rules
- Prefer edits in the existing HTML, CSS, and JavaScript files rather than adding new frameworks.
- Treat assets/styles.css and assets/script.js as shared sources for site-wide styling and behavior.
- Preserve the existing page structure unless the user asks for a redesign.
- Keep the mobile experience polished and lightweight.
- Respect reduced-motion preferences and avoid unnecessary animation.
- When changing business details, update every page that refers to them.

## Validation
- Check that modifications do not break page navigation, contact flows, or interactive elements.
- Make sure generated changes remain suitable for static hosting and direct file deployment.
- Favor minimal, reviewable edits.
